BƯỚC 02 / KẾT NỐI TÀI KHOẢN
Kết nối Gemini
Chưa bật


Cần có “Custom apps” trong Gemini → Settings → Connected Apps. Google hiện giới hạn tính năng cho tài khoản cá nhân 18+, tại Mỹ, tiếng Anh và bật Keep Activity. Điều kiện từ Google ↗


Tạo địa chỉ để Gemini tìm thấy dự án
Mở terminal trong thư mục Code Bridge và chạy lệnh bên dưới. Cần cài cloudflared. Lệnh tạo URL public tạm thời cho cổng MCP có xác thực.
npm run gemini:tunnel
Cổng đích: http://127.0.0.1:3212. Hãy trỏ tunnel đúng địa chỉ này.


Thêm Code Bridge vào Gemini
  1. Dán địa chỉ MCP dưới đây vào Gemini → Connected Apps → Add a custom app.
  2. Mở trang xác thực mà Gemini hiển thị. Giữ trang đó mở.
  3. Quay về đây, đối chiếu mã yêu cầu và địa chỉ trả về, rồi bấm Cho phép.
  4. Trở lại Gemini, dùng @ chọn Code Bridge và thử đọc file.
Bật cổng Gemini để nhận URL MCP.
Chưa nhận lệnh MCP qua kết nối Gemini.
Dùng cùng URL cho nhiều tài khoản đủ điều kiện; duyệt riêng từng yêu cầu. URL tạm thay đổi khi tạo tunnel mới. Đổi URL, đổi workspace hoặc đóng ứng dụng sẽ cần kết nối lại. Có thể dùng domain HTTPS cố định với reverse proxy của bạn.

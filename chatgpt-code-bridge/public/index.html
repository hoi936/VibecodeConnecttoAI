  1. Trong Ứng dụng Gemini ↗, ngắt/kết nối lại custom app Code Bridge. Nếu không có nút kết nối lại, xóa app cũ rồi thêm lại bằng URL MCP có /mcp bên dưới.
    2. 
                
  2. Giữ trang xin quyền mở; quay lại Code Bridge → Yêu cầu kết nối. Chỉ bấm Cho phép khi dòng quyền ghi rõ “Đọc và sửa file”.
    3.

    4.

                02A · TRÊN MÁY CỦA BẠN
                
Tạo URL HTTPS và bật cổng

                
Nhấn nút bên dưới. Code Bridge sẽ tự cài cloudflared nếu cần, tạo URL HTTPS và bật cổng Gemini. Giữ ứng dụng mở trong khi sử dụng.

                

                  

                    
                    
                  

                  
Chưa tạo URL.

                  
                  
                

                

                  Dùng lại kết nối sau khi bật máy · URL HTTPS cố định
                  
Quick Tunnel tạo địa chỉ mới sau khi chạy lại. Để giữ nguyên app Gemini, bạn cần một hostname cố định, ví dụ Cloudflare Named Tunnel.

                  
    
                    
  1. Trong hướng dẫn Cloudflare Tunnel ↗, tạo tunnel và hostname trên domain Cloudflare của bạn. Trỏ Service URL đến http://127.0.0.1:3212.
    2. 
                    
  2. Cài tunnel chạy cùng hệ điều hành sau khi bật máy. Giữ Code Bridge mở để cổng MCP local hoạt động.
    3. 
                    
  3. Nhập URL gốc ở ô bên dưới, bấm Bật cổng Gemini, rồi dán URL có /mcp ở cột bên phải vào Gemini một lần. Những lần sau Code Bridge tự khôi phục quyền còn hạn; tunnel bên ngoài cũng phải đang chạy.
    4. 
                  

                  
Việc tạo hostname cố định cần tài khoản và domain Cloudflare hoặc dịch vụ HTTPS cố định khác. Code Bridge không thể giữ nguyên URL Quick Tunnel qua lần khởi động mới.

                  

                    
                    
                    
URL gốc chỉ dùng trong Code Bridge; ứng dụng sẽ tạo URL MCP hoàn chỉnh cho Gemini.

                    

                      
                      
                    

                  

                

                
Cổng đích của tunnel: http://127.0.0.1:3212. Không trỏ tunnel vào dashboard 3213.

              

              

                02B · TRONG GEMINI
                
Sao chép đúng URL MCP

                

                  URL DÁN VÀO GEMINI · PHẢI CÓ /mcp
                  Bật cổng Gemini để nhận URL MCP.
                  
                

                
    
                  
  1. Bấm Copy URL MCP phía trên. Mở trang Ứng dụng Gemini ↗, tìm Ứng dụng tùy chỉnh cho Spark và dán URL vào ô “URL của máy chủ MCP”. Bấm Tiếp theo.
    2. 
                  
  2. Nếu Gemini mở trang xin quyền, giữ trang đó mở. Quay lại Code Bridge, đối chiếu mã yêu cầu và địa chỉ trả về rồi bấm Cho phép.
    3. 
                  
  3. Trở lại Gemini, gõ @ để chọn app vừa thêm. Yêu cầu đọc một file trong dự án để kiểm tra.
    4. 
                

                

                  
                  
                

                
Chưa nhận lệnh MCP qua kết nối Gemini.

                

                  Nếu Gemini báo lỗi kết nối
                  
    
                    
  • “URL không phải máy chủ MCP hợp lệ”: kiểm tra URL trong Gemini kết thúc bằng /mcp; không dùng URL gốc của tunnel.
    • 
                    
  • “Đăng ký OAuth tự động không thành công”: kiểm tra tunnel và cổng còn chạy, rồi thử lại với URL MCP. Không dùng Runtime API Key của ChatGPT ở đây.
    • 
                    
  • 502 hoặc không mở được trang xin quyền: kiểm tra trạng thái URL tự động ở bên trái và thử tạo lại URL nếu tunnel đã ngắt.
    • 
                    
  • Code Bridge hiển thị 0 quyền: đây là trạng thái bình thường trước khi duyệt. Yêu cầu chờ duyệt sẽ xuất hiện khi Gemini bắt đầu xác thực.
    • 
                  

                

                
Dùng Quick Tunnel: sau khi chạy lại, URL thay đổi nên cần cập nhật app trong Gemini và duyệt quyền mới. Dùng hostname cố định: Code Bridge khôi phục quyền còn hạn khi mở lại.

    Đang tải…
    
          
          
    Đã thêm công cụ MCP. Mở lại cấu hình MCP trong Antigravity để tải server.
    
        
    
        
    
          
    CẤU HÌNH THỦ CÔNG
    Nội dung mcp_config.json
    
          
    Dùng trong .agents/mcp_config.json của dự án hoặc cấu hình toàn cục ~/.gemini/config/mcp_config.json. URL localhost phải truy cập được từ nơi Antigravity chạy.
    
          
    Đang tải…
    
        
    
        
    
          
    BƯỚC 02 · MODEL
    Chọn model trong Antigravity
    
          
    Muốn chat với Argon ngay trong editor, mở dự án bằng VS Code, dùng extension Google Antigravity chính thức, đăng nhập tài khoản được cấp Argon rồi chọn model ở menu dưới ô chat. Antigravity IDE độc lập không có Argon 4. Google yêu cầu Pro trả phí hoặc Ultra; Pro dùng thử chỉ được cấp trên thiết bị cao cấp đủ điều kiện. Nút thêm MCP ở bước 01 chỉ thêm công cụ Code Bridge, không thay đổi quyền truy cập model.
    
          
    Muốn tự xây panel Argon riêng bằng API cần Gemini API paid tier với phí API riêng; Google AI Pro không bao gồm lượt gọi Argon qua API.
    
          
    Xem bảng model chính thức của Google ↗
    
          
    Nếu bạn cần trò chuyện trực tiếp trên Gemini Web, dùng mục Gemini Web của Code Bridge. Đó là một kết nối khác với model selector của Antigravity.
